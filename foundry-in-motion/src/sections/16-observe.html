Operate and observe: tracing, monitoring, alerts

Tracing, monitoring and evaluation share one data model. Foundry captures inputs, outputs, tool usage, retries, latencies and token consumption for every run, so you can answer "where did this response come from?" and "which step added the latency?"

Traces are built from spans (single operations, nestable) with attributes, following the OpenTelemetry GenAI semantic conventions (development status, may change). Microsoft and Cisco Outshift contribute conventions for multi-agent workflows, integrated in Foundry, Microsoft Agent Framework, LangChain and LangGraph.

What is capturedUser inputs and agent outputs, tool calls and results, token consumption, duration and latency.
StatusTracing is GA for prompt and hosted agents. Workflow and external agents are in preview.
Where it livesAzure Monitor Application Insights; view in the Foundry portal (Operate › Tracing) or in Azure Monitor.
Replay and annotateReplay agent traces; annotate with human feedback; log end-user feedback.
Traces to datasetsConvert traces into evaluation datasets to test against real behavior.
Protect sensitive contentRestrict access to sensitive content in traces; Entra authentication for trace ingestion.

Build › Agents › your agent › Monitor tab Preview. Summary cards on top, charts below, for the selected time range.

MetricRead it as
Token usageHigh usage can mean verbose prompts or responses worth optimizing.
LatencyAbove about 10 seconds can indicate model throttling, complex tool calls or network issues.
Run success rateBelow about 95% warrants investigating failed runs.
Evaluation metricsScores from evaluators on sampled outputs; interpretation varies by evaluator.
Red teaming resultsOutcomes of scheduled scans; failed scans indicate risks to remediate.

Data is stored in your connected Application Insights resource, so retention and billing follow its configuration. For log-based views you also need Log Analytics Reader.

Assign the project's managed identity the Foundry User role so continuous evaluation rules can run. A Notification Center and Insights surface issues and suggested improvements, and the fleet-level Operate panes add cost and token anomaly tracking.

The control plane can also register custom agents from other platforms so you see Foundry, Microsoft and non-Microsoft agents in one fleet view.

  1. Connect Application Insights to the projectTracing and the Monitor dashboard read from it.
  2. Grant accessLog Analytics Reader (and Privileged Monitoring Data Reader if tables are protected).
  3. InstrumentPrompt and hosted agents emit traces by default; for your own code use OpenTelemetry with the Foundry SDK, or framework integrations.
  4. Open Operate › Tracing and the agent's Monitor tabVerify spans, tokens and latency.
  5. Turn on continuous evaluation and alertsUse the gear icon in Monitor settings.
