07 · Ground the answer

Build a RAG pattern agent

A model alone has a knowledge cutoff and cannot see your content. Retrieval-augmented generation (RAG) lets an agent look things up first, then answer from what it found, with citations. Foundry offers three retrieval paths that scale from a handful of files to an enterprise knowledge layer.

Pick the lightest path that fits. You can combine them on one agent.

PathBest whenWhat you manage
File searchA few user or developer files; fastest way to a working RAG agent.Upload files; the service builds a vector store. In standard setup, vector stores live in your own Azure AI Search.
Azure AI Search toolYou already have a search index, or need custom indexing and ranking.Your index and its connection to the project.
Foundry IQ knowledge baseSeveral sources, permission-aware answers, shared by many agents.A knowledge base with knowledge sources; Azure AI Search powers it behind the scenes.
Web search / Bing groundingFresh public information.Tool configuration; review data-sharing for web tools.

Build one, step by step

  1. Choose the retrieval pathUse the table above. Start with file search to prove value, move to Foundry IQ when content is spread across sources or needs permissions.
  2. Create the knowledgeUpload files (Build › Data), or create a knowledge base (Build › Knowledge) with a search service and one or more knowledge sources.
  3. Create the agent and attach the knowledgeIn Build › Agents, add the file search tool, the Azure AI Search tool, or connect the knowledge base.
  4. Instruct for groundingTell the agent to answer only from retrieved content, to cite sources, and to say when it does not know.
  5. Test with hard questionsInclude questions with no answer in your content, and questions a user should not be allowed to see.
  6. Evaluate retrieval and groundednessUse the RAG evaluators: Retrieval, Document Retrieval, Groundedness, Relevance and Response Completeness. Gate releases on the scores.
Pick the right memory of the world. Use memory for what an agent learns about a user over time, a Foundry IQ knowledge base for curated organizational content, and file search for documents a user provides during an interaction.
