02 · Know your way around

Every tab in the Foundry portal

The current portal splits features across six top-level sections, each with its own left pane. Click through the replica below to see what lives where, what it is scoped to, and which doc explains it.

New Foundry
Scope mattersHome, Discover, Build act on the project you selected. Operate spans all projects. Manage targets the selected project and its parent resource.
Switch projects firstUse the project name dropdown in the upper left before acting on a different project, especially in Manage.
The UI movesThe Foundry portal is updated frequently. If a step does not match, look for the equivalent option in the current UI.
