04 · Choose and deploy

The model catalog and how you deploy it

Foundry gives you more than 10,000 models in two families. How you deploy a model decides where data is processed, how you pay, and how predictable latency is.

Sold by Azure

Hosted and operated by Azure, billed through your Azure subscription, covered by Azure SLAs and supported by Microsoft. Includes all Azure OpenAI models plus selected models from other top providers (for example DeepSeek, Meta, Mistral AI, Cohere and xAI collections).

From partners and community

Sold and operated by the provider (for example Anthropic's Claude). They require an Azure Marketplace subscription, and the provider sets license terms and price. You need Marketplace permissions to subscribe before you deploy.

Deployment types at a glance

Three categories: standard (pay per token), provisioned (reserved capacity) and batch (discounted, asynchronous). Within standard and provisioned you pick global, data zone or geography processing.

Start with Global Standard. It launches first when a new model releases, has the lowest price, and the broadest region coverage. Move only for a specific reason: data residency, reserved throughput, or asynchronous batch.

Which deployment type should I pick?

Model router: one deployment, many models

Model router is a trained model that routes each prompt to a suitable underlying model in real time, balancing quality, cost and latency, packaged as a single deployment. You deploy it like any other model.

Supports Global Standard and Data Zone Standard. Choose a model subset to control the pool. The effective context window is limited by the smallest underlying model. Claude models must be deployed first before router can use them.

More ways to get to a model

Instant access PreviewCall a supported model by name with no deployment. West US 3 only during preview.
Fine-tuningTraining, hourly hosting (even when idle) and per-token inference are charged. Remove deployments you do not need.
BenchmarksLeaderboards and compare-models in the catalog help you shortlist before you evaluate on your own data.
Bring your own modelConnect models behind your own AI gateway to use Foundry agent capabilities. You own responsible-AI mitigations for those models.
LifecycleModels move from preview to GA to legacy and retirement. Check the lifecycle policy before you commit a long-lived workload to a model version.
