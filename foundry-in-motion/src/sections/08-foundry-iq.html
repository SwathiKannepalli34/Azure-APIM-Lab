08 · Knowledge layer

Foundry IQ: a permission-aware knowledge base for agents

Foundry IQ lets you create a configurable, multi-source knowledge base that gives agents grounded, permission-aware answers from your organization's data. Multiple agents can share the same knowledge base.

GA vs preview. Some Foundry IQ features are generally available while others remain in preview, depending on the Search Service REST API version you use. The Foundry and Azure portals provide preview access to all agentic retrieval features. Check the migration guidance on the Foundry IQ page.

Agentic retrieval decomposes a complex question into subqueries, runs them in parallel across sources, reranks semantically, and returns unified results that respect the caller's permissions.

Knowledge baseThe top-level resource. Defines which knowledge sources to query and how retrieval behaves, including the retrieval reasoning effort (minimal, low or medium).
Knowledge sourcesConnections to indexed or remote content: Blob Storage, SharePoint, OneLake and the public web. A knowledge base references one or more.
Agentic retrievalMulti-query pipeline with an optional LLM for query planning; keyword, vector or hybrid queries across indexed and remote sources.
Automated ingestionChunking, vector embeddings and metadata extraction for indexed sources, with scheduled indexer runs for incremental refresh.
PermissionsSynchronizes ACLs for supported sources, honors Microsoft Purview sensitivity labels, and runs queries under the caller's Microsoft Entra identity.
CitationsReturns extractive data with citations so agents reason over raw content and answers trace back to documents.

Set it up

  1. Open Build › KnowledgeMake sure New Foundry is on and select your project.
  2. Create or connect a search serviceIt must support agentic retrieval. For a proof of concept use the free tier of Azure AI Search and the free allocation of tokens for agentic retrieval.
  3. Create a knowledge baseAdd one knowledge source at a time, then configure retrieval behavior.
  4. Build › Agents: connect the knowledge baseCreate or select an agent and connect it. Refine in the playground.
The playground is a simplified proof-of-concept path. When you move to code, configure managed identities and permissions to match your security requirements.

Create knowledge sources, create a knowledge base that references them, connect an agent, then send messages and refine. You can use a knowledge base from Foundry Agent Service, Microsoft Agent Framework or any custom app through the knowledge base REST API or Azure AI Search SDK clients. A private agentic retrieval tutorial covers inbound and outbound private connectivity.

After you connect a knowledge base to an Agent Service agent you can also add that agent to Microsoft Copilot Studio Preview.

Fabric IQ PreviewSemantic layer for Microsoft Fabric: ontologies, semantic models, graphs and data agents over OneLake and Power BI.
