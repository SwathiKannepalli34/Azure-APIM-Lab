01 · What Foundry is

One platform, one management plane

Foundry unifies agents, models and tools under a single management grouping with enterprise capabilities built in: tracing, monitoring, evaluations and customizable enterprise setup. Role-based access, networking and policy are managed in one place under one Azure resource provider namespace.

AgentsDeclarative prompt agents (including voice), workflows, and hosted agents that run your own code in a managed runtime.
ModelsMore than 10,000 models from Microsoft, OpenAI, Anthropic, Meta and others, deployed with the billing and residency option you choose.
Tools & knowledgeA Toolbox packages tools behind one MCP endpoint; Foundry IQ and memory ground agents in your content and context.
ObservabilityTrace and monitor agents and models, with dashboards for tokens, latency, success rate and evaluation scores.
GuardrailsContent safety controls applied at four intervention points on models and agents.
GovernanceControl plane, Entra identity, Azure Policy, Defender, Purview and an AI Gateway for token limits.

Choose how much you want to own

Most work on Foundry centers on an agent: a model paired with instructions and tools that can reason over a request and take action. The main decision is how much of the runtime you want to control. You can start declarative and move to code later.

Prompt agentInstructions + model + tools, defined in the portal or SDK. Foundry hosts and runs it. Nothing to deploy.
Workflow agent PreviewOrchestrates several agents and steps when one task spans more than one agent.
Hosted agentYour code and framework (Agent Framework, LangGraph, Semantic Kernel, custom) packaged as a container. Foundry gives it an endpoint, identity, scaling and observability.
Not building an agent yet? If you only need to send prompts to a model with no tools or orchestration, start with a single model call. Add an agent later only if you need tools or orchestration.
