Microsoft Foundry demo

Observability · Guardrails · Evaluations · Governance — connecting…

1. Observability: traced chat

Every call is traced with OpenTelemetry to Application Insights (tokens, latency, spans). Query it with kql/queries.kql.

2. Guardrails: red-team prompts

Benign and adversarial prompts against the custom guardrail. Platform blocks and model refusals are reported separately.

3. Evaluations: quality gate

Generates answers for a small dataset and scores relevance, coherence and groundedness with an LLM judge (about 1 minute).

4. Governance: posture and policy

Checks the Foundry account configuration and Azure Policy compliance for the resource group.
